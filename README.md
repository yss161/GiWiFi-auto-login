# giWiFi 校园网自动认证

一个用于 **giWiFi / gportal** 校园网认证页面的 Tampermonkey 用户脚本，打开登录页面后自动填写账号密码并提交，省去每次手动登录的麻烦。

## 功能特性

- 🔐 **自动填写并提交**：进入认证页面后自动填入账号密码并点击登录按钮。
- 💾 **账号本地保存**：通过 Tampermonkey 的 `GM_setValue` 保存账号信息，不会出现在脚本源码中。
- 🧩 **多选择器兼容**：内置多种常见输入框 / 按钮选择器，适配不同版本的 giWiFi 认证页。
- 🛡️ **验证码保护**：检测到验证码时自动停止提交，改为提示手动填写。
- 🔔 **状态提示**：页面右下角显示当前运行状态（填写中 / 提交中 / 出错）。
- ⚙️ **菜单配置**：通过 Tampermonkey 菜单即可设置账号、开关自动提交、清除已保存信息。

## 安装

1. 在浏览器中安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展。
2. 打开 `giwifi-auto-login.user.js` 文件，Tampermonkey 会自动弹出安装页面；或直接将文件拖入浏览器。
3. 点击「安装」完成。

## 使用

1. 第一次使用前，点击浏览器 Tampermonkey 图标 → **设置 giWiFi 账号**，输入校园网账号和密码。
2. 打开校园网认证页面（`http://你的校园网ip/gportal/web/login`），脚本会自动填写并提交。
3. 若页面出现验证码，脚本会停止自动提交，请手动填写验证码后点击登录。

> 也可以在脚本源码顶部的 `DEFAULT_CONFIG` 中直接填写账号密码，但**不推荐**，因为这样会把账号信息暴露在源码里。

## 菜单命令

在 Tampermonkey 菜单中可执行以下操作：

| 命令 | 说明 |
| --- | --- |
| 设置 giWiFi 账号 | 设置或修改校园网账号、密码 |
| 开启 / 关闭自动提交 | 切换是否自动点击登录按钮（刷新页面后生效） |
| 清除已保存的账号信息 | 删除本地保存的账号和密码 |

## 配置项说明

脚本顶部的 `DEFAULT_CONFIG` 支持以下字段：

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `username` | `''` | 校园网账号 |
| `password` | `''` | 校园网密码 |
| `usernameSelector` | `#loginForm input[name="user_account"]` | 账号输入框选择器 |
| `passwordSelector` | `#loginForm input[name="user_password"]` | 密码输入框选择器 |
| `submitSelector` | `#btn_login` | 登录按钮选择器 |
| `autoSubmit` | `true` | 是否自动提交 |
| `submitDelayMs` | `350` | 提交前的延迟（毫秒） |

如果页面结构发生变化导致脚本找不到输入框或按钮，可以在菜单里配置账号后，手动修改源码中的选择器。

## 匹配规则

脚本默认匹配以下地址：

```
http://你的校园网ip/gportal/web/login*
```

如果所在学校的认证地址不同，请修改脚本头部的 `@match` 规则，或自行添加对应的地址。

## 工作原理

1. 脚本在页面加载完成后，从 Tampermonkey 存储中读取账号信息。
2. 依次尝试内置的多种选择器，定位账号输入框、密码输入框和登录按钮。
3. 检测页面是否存在验证码；若存在则停止自动提交并提示。
4. 通过原生 `value` setter 填写输入框，并派发 `input` / `change` / `blur` 事件，确保前端框架能感知值变化。
5. 延迟指定时间后点击登录按钮（按钮自身的 `onclick` 会处理 AES 加密和动态参数）。

## 注意事项

- 账号密码保存在浏览器的 Tampermonkey 存储中，**不会上传到任何服务器**，但仍建议不要在公共电脑上使用。
- 若认证页面改版导致选择器失效，可通过菜单手动设置账号，并更新源码中的选择器。
- 脚本不会绕过验证码，遇到验证码需要手动输入。
- 请遵守所在学校的网络使用规定。

## 兼容性

- 浏览器：Chrome / Edge / Firefox 等支持 Tampermonkey 的浏览器。
- 脚本管理器：Tampermonkey（推荐）、Violentmonkey。
